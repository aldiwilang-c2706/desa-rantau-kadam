# Website & Sistem Informasi Administrasi Desa Rantau Kadam

Stack: PHP Native 8.1+, MySQL/MariaDB, PDO, Bootstrap 5.3, Bootstrap Icons.

Fitur publik: Beranda, Profil, Berita, Detail Berita, Pengumuman, Detail Pengumuman, Galeri, Aparatur, Dokumen Publik, Kontak + Maps.

Fitur admin: Dashboard, CRUD Berita, Pengumuman, Galeri, Potensi Desa, Perangkat Desa, Dokumen Publik, Profil, Pesan Masuk, Users, log aktivitas.

Keamanan: prepared statements, password_hash/password_verify, CSRF, session regeneration, XSS escaping, MIME validation upload, random filename, batas ukuran file, dan proteksi eksekusi PHP di uploads.

Untuk instalasi lihat TUTORIAL.md.
